Lis

Let - it - shine

Lis (Let - it - shine) is a TUI program written in C which helps beginners (and everynone else) at creating schematics.

Main Features

Lis is open-source and everyoune can contribute to the Project. Interested? Have a look at the notes about contributing.

Because its entirely based on C and ncurses, Lis is extremly light on performace. This allows old machines to run it without a problem.

Lis helps you by calculating values for resistors and other parts that fit for your needs and projects.

Analyzing and identifying Components to get values (e.g. by inputting color codes) is the second big focus of Lis.

Contributing

Lis is open-source, which means anyone can contribute to the Project. To start, simply read the Contributing Guidelines in the Documentation. Then you can either open Pull Requests or fix Issues (Issues labeled "good first issue" or "contribution welcome" ) are a good starting point.

Reporting Issues

Issues can be reported on the Codeberg Issue site. Be sure to give a detailed description and steps to reproduce the issue, As well as label the issue correctly.

Quick Install

it's recommended to read trough the documentation article: Getting Started

Linux:

git clone https://codeberg.org/LordAxi/Lis
cd Lis
./install.sh

Windows

Windows is currently not supported by Lis
