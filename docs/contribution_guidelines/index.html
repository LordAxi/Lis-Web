Contribution Guidelines

  1. Make sure a similar issue / pull request doesn't already exist.
  2. Give detailed information about the issue / pull-request.
  3. Test the code or label it as untested.
  4. Use comments to explain your code. But don't write comments in every line.
  5. Try to optimize the performace of your code.
  6. Style:

    The tab length is 4 spaces;
    Variables use snake case;
    Functions and Classes use camel case;
    Constants are in caps;
    Opening curly braces share a line with the e.g. function;
    Closing curly braces are on their own line;

  7. Be ready to change your code to fit these guidelines.
