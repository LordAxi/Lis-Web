Installation

Linux

Compiling

!Note: "install.sh" moves Lis into "/usr/bin" and creates config files in ".config/Lis".


Prerequisites: git

git clone https://codeberg.org/LordAxi/Lis
cd Lis
./install.sh

Pre-Build Binaries

Pre-Build Binaries can be downloaded from the codeberg releases page.
